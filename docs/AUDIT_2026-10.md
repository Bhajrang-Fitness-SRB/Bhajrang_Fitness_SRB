# Audit, October 2026 (all fixes below are already applied to the live database)

| # | Problem | Effect | Fix |
|---|---|---|---|
| 1 | `approve_member` read an unassigned PT-package record | Every registration approval without a PT package failed (HTTP 500, `record "v_pt" is not assigned yet`) | `20261025000000_rbf_fix_approve_member_pt.sql` (+ clear messages for missing package/amount) |

| 3 | CSV member import wrote to `members` with the public key | Always refused (401); and it would have reset joining dates to today | `20261027000000_rbf_admin_import_members.sql` (staff-checked, per-row, creates login passcodes for new members) |
| 4 | App hid the real approval error | Staff only saw "Approval failed" | App now shows the real reason |
| 5 | `kiosk_register_device` unlimited | Device list could be flooded | Max 25 waiting devices, name capped |
| 6 | 4 helper functions had a changeable search_path | Supabase security warning | Fixed |
